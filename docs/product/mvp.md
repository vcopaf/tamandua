# Alcance Del MVP

El MVP cubre proyectos, sesiones manuales y automáticas, inspección de pantallas, reglas deterministas, hallazgos candidatos, revisión humana, evidencias, ejecución Playwright y reportes HTML, Markdown y JSON.

El alcance detallado, criterios de aceptación y fases de entrega se mantienen en la especificación funcional proporcionada para este proyecto y se implementarán una fase a la vez.
